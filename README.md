## 🔍 &nbsp;RAG & Agentic Systems Knowledge

### RAG Architectures

| Type | Description |
|:---|:---|
| **Naive RAG** | Chunk → Embed → Retrieve → Generate baseline |
| **Advanced RAG** | Query rewriting, re-ranking, hybrid search, parent-child chunking |
| **Agentic RAG** | LLM autonomously decides when/what/how to retrieve |
| **Corrective RAG (CRAG)** | Self-grades retrieved docs, falls back to web search if irrelevant |
| **Self-RAG** | LLM reflects on its own outputs, iteratively improves retrieval |
| **GraphRAG** | Knowledge graph-based retrieval — entity relationships & community summaries |
| **LightRAG** | Graph + vector hybrid — dual-level retrieval for local & global context |
| **HyDE** | Hypothetical Document Embeddings for zero-shot dense retrieval |
| **Multi-hop RAG** | Chain of retrievals for complex multi-step questions |

### 🔦 Featured: LightRAG (HKUDS) — Custom Fork

> Forked from [HKUDS/LightRAG](https://github.com/HKUDS/LightRAG) — the Graph + Vector hybrid RAG framework

**My custom additions on top of LightRAG:**
- ✅ &nbsp;**User-wise document access control** — per-user document namespacing & permission layer
- ✅ &nbsp;**Multi-workspace environment** — isolated workspaces per tenant/project with shared graph layer
- ✅ &nbsp;**Custom ingestion pipelines** — PDF, DOCX, scanned docs, tables integrated into LightRAG's insert flow
- ✅ &nbsp;**vLLM backend integration** — plugged vLLM for faster inference instead of default OpenAI-compatible endpoint

### Agent Architectures

| Pattern | What I Build |
|:---|:---|
| **Agent Harness** | Custom agent loops, tool registries, decision & routing engines |
| **Multi-Agent Supervisor/Worker** | Hierarchical delegation — supervisor spawns & coordinates sub-agents |
| **Swarm Architecture** | Peer agents collaborating with shared memory and handoffs |
| **Reflection Agents** | Self-critique loops — plan → act → observe → reflect → retry |
| **Tool-Calling Agents** | Autonomous tool selection (SmolAgents, DeepAgents, LangGraph nodes) |
| **LangGraph Workflows** | Stateful cyclic graphs — conditional edges, parallel branches, memory checkpoints |
| **LLM Middleware** | Pre/post hooks to intercept, validate, override LLM I/O at pipeline level |
| **Guardrail Override** | Custom fallback logic when safety layers fail — full flow stays controlled |
