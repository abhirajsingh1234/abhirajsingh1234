### 👋 &nbsp;About Me

> *AI/ML Engineer specializing in production-grade agentic systems — from raw model training to full-scale deployment. I work across the entire AI stack: fine-tuning open-source LLMs, building multi-agent pipelines, designing industry-scale RAG systems, and deploying on any infra — cloud or bare-metal.*

&nbsp;

- 🤖 &nbsp;Specialized in **Agentic AI** — Multi-Agent Architecture, Agent Harness, Agent-to-Agent Delegation
- 🔍 &nbsp;Expert in **Agentic RAG** — Corrective, Adaptive, Self-Reflective, GraphRAG pipelines
- 🧬 &nbsp;Deep experience in **LLM Fine-Tuning** — LoRA, QLoRA, full fine-tune + Quantization (GGUF, AWQ, GPTQ)
- 📄 &nbsp;**Document Intelligence** — Multi-modal extraction using VLMs, OCR, LayoutLM, DocTR, Surya
- 🎙️ &nbsp;**Voice AI** — Whisper, Speaker Diarization, Emotion & Sentiment from Audio (open-source only)
- 👁️ &nbsp;**YOLO Training** — Custom object detection pipelines (YOLOv8 / YOLOv11)
- 🔒 &nbsp;**LLM Middleware & Flow Control** — Intercept, control & override LLM pipelines beyond guardrails
- ☁️ &nbsp;**Deployment** — AWS · Azure · RunPod · Bare-Metal · Private Cloud · Edge
- 🛠️ &nbsp;Fluent in any model — proprietary (GPT-4o, Claude, Gemini) or open-source (Mistral, LLaMA, Phi, Qwen, DeepSeek)
