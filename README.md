## Expertise
 
### Agentic AI & RAG Systems
 
Production experience building retrieval architectures from basic semantic search through advanced Agentic RAG — where LLMs autonomously decide when to fetch data, how to reframe queries, and how to self-grade responses. Specializations include **Corrective RAG (CRAG)**, **Self-RAG**, and **GraphRAG**.
 
**LightRAG Platform Enhancements**
- **Multi-Workspace Isolation** — Tenant-isolation framework with strictly separated knowledge graphs, preventing data crossover and improving contextual accuracy at scale.
- **Role-Based Document Privacy** — Access control and role management layer enforcing strict authorization rules over ingested documents.

### Model Capabilities
 
| Domain | Skills |
|---|---|
| **Text & LLMs** | Prompting, fine-tuning (LoRA), quantization (GGUF · AWQ · GPTQ), reasoning optimization |
| **Vision & Multimodal** | VLM pipelines, document extraction, cross-modal reasoning, YOLO custom training |
| **Speech & Voice** | STT pipelines, transcription formatting, speaker diarization, voice emotion/sentiment |
| **Embeddings & Reranking** | Dense vector representations, cross-encoder reranking, hybrid search |
 
### Deployment & Infrastructure
- **Cloud:** AWS · Azure (Bedrock, SageMaker, AKS) — production LLM application deployments
- **Self-Hosted:** vLLM high-throughput inference, bare-metal GPU servers, RunPod serverless GPU
- **Linux:** Native AI deployment configuration and management
